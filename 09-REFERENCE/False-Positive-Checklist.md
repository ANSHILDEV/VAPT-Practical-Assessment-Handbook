# False-Positive Validation

- [ ] Reproduce safely more than once.
- [ ] Compare with baseline.
- [ ] Change one input at a time.
- [ ] Rule out latency, caching and transient errors.
- [ ] Confirm endpoint and parameter.
- [ ] Establish security relevance and impact.
- [ ] Check compensating controls.
- [ ] Distinguish confirmed vulnerability from hardening recommendation.
- [ ] Record uncertainty honestly.
