# Quick Glossary

- VAPT: Vulnerability Assessment and Penetration Testing.
- BOLA/IDOR: Missing object-level authorisation.
- CSRF: Tricks a browser into sending an authenticated request.
- CORS: Browser mechanism controlling cross-origin response access.
- CSP: Content Security Policy.
- SSRF: Causes a server to make unintended requests.
- LFI/RFI: Local/remote file inclusion weaknesses.
- JWT: JSON Web Token; signed does not mean encrypted.
- TLS: Protects data in transit.
- IV/Nonce: Values used by cryptographic modes; requirements depend on algorithm.
- SAST/DAST: Static/Dynamic Application Security Testing.
- CVSS: Common Vulnerability Scoring System.
- CWE: Common Weakness Enumeration.
- CISO: Chief Information Security Officer.
