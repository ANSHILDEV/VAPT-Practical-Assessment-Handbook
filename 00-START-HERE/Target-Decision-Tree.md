# Target Decision Tree

- URL/website → `02-WEB/Web-Testing-Checklist.md`
- API specification or JSON endpoints → `03-API/API-Testing-Checklist.md`
- APK / installed Android or iOS app → `04-MOBILE/Mobile-Testing-Checklist.md`
- IP range / host list → `05-INFRASTRUCTURE/Infrastructure-Checklist.md`
- Source code → add manual review: trace input → validation → sensitive operation → output.
- Unsure → ask whether the supplied machine is a workstation, jump host or target, and what assets are in scope.
